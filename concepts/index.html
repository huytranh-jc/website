JoyCraft — 3 Website Concepts

Concept A

Aurora

Premium dark tech — nền indigo/violet, aurora glow, glassmorphism, typography sắc. Sang, modern, "AI-augmented".

Default: Dark · có Light mode
Home Careers
Concept B

Arcade

Bold & playful — gradient rainbow như logo JoyCraft, type bo tròn chunky, pill buttons, vui tươi. Đúng chất mobile casual.

Default: Light (vibrant) · có Dark neon mode
Home Careers
Concept C

Editorial

Clean startup/Swiss — sáng, tối giản, nhiều whitespace, serif Fraunces + accent xanh nhẹ. Chuyên nghiệp, đáng tin.

Default: Light · có Dark charcoal mode
